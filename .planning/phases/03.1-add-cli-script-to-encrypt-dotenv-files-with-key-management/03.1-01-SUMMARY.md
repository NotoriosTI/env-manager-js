## Decisions Made

- Refuse when DOTENV_PUBLIC_KEY already present (not silent overwrite) — prevents key mismatch from silent re-encryption (per research Pitfall 2)
- Refuse when .env.keys exists without force=true — preserves existing private key (critical for decrypt continuity)
- Use ESM top-level `import { PrivateKey, encrypt } from 'eciesjs'` in CLI module (not the CJS require workaround from the synchronous loader context)
